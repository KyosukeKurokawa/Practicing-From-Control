What is JavaScript? How did it get its name?

JavaScript is a programming language that makes websites interactive, and it was named after the popular language "Java".

What are the two ways you can run JavaScript?

We can run JavaScript either inside a web browser or on a server or computer using a tool called Node.js.

What is jQuery? Is it still popular today?

jQuery is a tool that made writing JavaScript much shorter and easier in the past, though it is no longer popular for new websites because modern JavaScript have replaced it.

What is the most popular front-end js library today?

The most popular front end JavaScript library today is react, which is widely used to build fast and modern website interfaces.

How does your code prevent the form from being submitted? Why do we need to prevent it?

people stop a form from submitting by using event.preventDefault(), which is necessary so the page does not automatically reload before your JavaScript code can check the user's input or send the data in the background.
