What is AJAX?

AJAX lets a web page send and receive data in the background without reloading the entire page.

Why do you put your JS Code in a separate file?

Putting JavaScript in a separate file keeps your code organized, reusable across pages, and easier to read and maintain.

How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?

Open DevTools, check the Console and Network tabs for problems, and click the file link next to a red error to see its exact line number.
