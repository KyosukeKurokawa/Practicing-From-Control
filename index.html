Question

The form tag has an "action" attribute. What does it do?

The action attribute specifies the URL or endpoint where the form's data is sent for processing when submitted.

The form tag has a "method" attribute. What does it do?

The method attribute defines the HTTP method used to transmit the form data to the server.

What is the difference between a "POST" and a "GET"?

GET appends the form data directly to the URL query string, whereas POST sends the data securely hidden within the HTTP request body.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button.

Pre-set value (using value="" or inner text, checked, selected) provides an actual initial value that gets submitted with the form. A placeholder (using placeholder="") is just a temporary, grayed-out hint text that disappears as soon as the user starts typing and is not submitted.

What are different ways to style your form?

We can style forms using external CSS stylesheets, internal style tags, or inline styles by applying CSS properties, such as the box model, flexbox, and pseudo-classes.

Why does the professor like to use flex?

Flexbox makes it easy to align labels and input fields side-by-side into clean, evenly spaced rows and manage responsive alignment.

What makes for a good mobile form?

A good mobile form features a stacked single-column layout, large tap targets, readable font sizes, and enough padding to easily tap and type on small screens without zooming.
